# Contributing

Contributions are welcome after the pre-alpha review.

Each case must:

1. Be original or have explicit compatible licensing.
2. Use only synthetic tools, identities, accounts, URLs, and secrets.
3. Contain no copied system prompt or private instruction.
4. Include a benign or adversarial label and expected observable behavior.
5. Pass `py -3.10 -m aasb.validate data/v0.1/cases.jsonl`.
6. Receive native-speaker review for its declared Arabic variety.

Do not submit real credentials, personal data, malware, or instructions that
target a real service.
