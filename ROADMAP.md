# Roadmap

Roadmap items are targets, not completion claims.

## v0.1 calibration candidate

- Complete two independent native-language reviews for every seed case.
- Resolve revision requests and measure reviewer agreement.
- Run three reproducible model or configuration baselines.
- Publish per-category results without an aggregate pass threshold.

## v0.2 dataset expansion

- Review and revise the generated 300-case draft candidate; its target size is reached but its language quality is unverified.
- Add contribution-level duplicate and near-duplicate checks.
- Document coverage gaps before adding more Arabic varieties.
- Define thresholds only after calibration evidence exists.

## Release gate

A public release remains blocked while any included case is `draft`, a model run
is partial, provenance is unresolved, or documentation overstates the evidence.
