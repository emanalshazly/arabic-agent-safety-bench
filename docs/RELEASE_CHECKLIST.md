# Release checklist

Record evidence beside every item. An unchecked item is not implicitly passed.

- [ ] Dataset validator passes on the exact release artifact.
- [ ] Every included case is `native_reviewed` through two distinct eligible reviews.
- [ ] Review agreement and revision counts are reported.
- [ ] No real credential, personal data, private prompt, or operational target exists.
- [ ] Provenance and license are documented for every included case.
- [ ] Baseline metadata reports full requested-case completion.
- [ ] Baseline responses score without missing or duplicate case errors.
- [ ] Fixture outputs are labeled as fixtures, not model results.
- [ ] Methodology, limitations, schema, and adapter contract match the release.
- [ ] A clean-environment quickstart has been executed and recorded.
- [ ] Release notes identify dataset hash, code commit, and known limitations.
- [ ] External publication has explicit maintainer approval.
